AirBridge Screenshot — Windows 预览版

1. 先把整个 ZIP 解压到一个固定文件夹。
2. 双击 AirBridgeScreenshot.exe。不需要安装 Python。
3. iPad 与电脑连接同一 Wi-Fi，用 iPad 相机扫窗口中的二维码。
4. 配对页先复制连接地址，再点「添加截图快捷指令」。
   添加后点快捷指令上的 …，将唯一 URL 里的 SETUP_URL 换成刚复制的完整地址，点 Done，再试发截图。
5. 电脑右下角出现预览即成功；可直接拖动图片，或 Ctrl+V 粘贴。

想以后不用手动打开：勾选「登录 Windows 后自动接收」。
不要只移动 EXE，或删除 _internal 文件夹。移动整个文件夹后重新勾选自动启动。

二维码打不开：电脑窗口点「允许局域网连接…」，按 Windows 提示完成授权。
此授权只允许专用网络、本地子网的传图端口与 UDP 5353 设备发现。仅在信任的网络上把网络类型改为「专用」。
校园网如果禁止设备互访，需要可互访的网络。代理/VPN 也可能影响连接。

页面能打开但发图超时：连接方式改成「当前 IP」，重新扫码复制地址。
此备用方式换网络或 IP 改变后，可能需要再次更新快捷指令地址。

配对页提供通用快捷指令模板，不用从头添加动作；也保留了手动创建说明。
不要把含有个人配对码的二维码/连接地址公开分享。

只通过快捷指令按钮截屏发送；按系统截屏键不会自动发送。
图片在局域网直传，不需要 iCloud 会员，不要求注册 Cloudflare。
收到截图会覆盖当前剪贴板；预览不会自动保存所有截图。
只在拖动时生成 PNG 临时文件，24 小时后自动清理。

退出：右键托盘图标 → 退出接收器。
卸载：取消自动启动，退出后删除解压目录即可。
配置和拖动缓存：%USERPROFILE%\.airbridge-screenshot-community
